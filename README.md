# نظام إدارة محل زفرية

## التشغيل السريع

```bash
pip install PyQt5
python main.py
```

## المميزات
- 📊 لوحة تحكم مع إحصائيات فورية
- 🛒 نقطة بيع كاملة الوظائف
- 📦 إدارة المنتجات (إضافة/حذف/تعديل)
- 🗃️ تتبع المخزون الكامل
- 📈 تقارير يومية تفصيلية
- ⚠️ تنبيهات المخزون المنخفض
