# نظام إدارة محل الظافرية

## التشغيل السريع

```bash
pip install PyQt5
python main.py
```

## المميزات
- 📊 لوحة تحكم مع إحصائيات فورية
- 🛒 نقطة بيع كاملة الوظائف
- 📦 إدارة المنتجات (إضافة/حذف/تعديل)
- 🗃️ تتبع المخزون الكامل
- 📈 تقارير يومية تفصيلية
- ⚠️ تنبيهات المخزون المنخفض
- 📊 **قسم Analytics محمي**: لعرض الأرباح والتحليلات التفصيلية
- 🔐 **نظام تغيير كلمة المرور**: عبر التحقق بالبريد الإلكتروني ورمز التأكيد

## البيانات التجريبية
يحتوي النظام على 6 منتجات تجريبية:
- شبشب DC مقاس 42 (ش42DC)
- شبشب Adidas مقاس 40 (ش40AB)
- شبشب DC مقاس 38 (ش38DC)
- دفتر A4 (د38A4)
- دفتر A5 (د50A5)
- قميص رجالي (ق40SB)

جرب البحث عنهم في نقطة البيع!

## معلومات هامة للأمان

### كلمة المرور الافتراضية لقسم Analytics:
- **كلمة المرور الافتراضية**: `admin123`
- يمكنك تغييرها عبر زر "🔐 تغيير كلمة المرور" في الواجهة الرئيسية

### ميزات الأمان:
- ✅ لا تظهر الأرباح في لوحة التحكم الرئيسية
- ✅ لا تظهر الأرباح في رسالة إتمام البيع
- ✅ قسم Analytics محمي بكلمة مرور يعرض جميع الأرباح
- ✅ نظام تغيير كلمة المرور عبر التحقق بالبريد
