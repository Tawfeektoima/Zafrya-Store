# 🔐 نظام الحماية والترخيص

نظام حماية متقدم يربط البرنامج **بجهاز واحد فقط** لمنع النسخ غير المشروع.

---

## 🎯 كيف يعمل النظام؟

### للمطور (أنت):

1. **العميل يشغّل البرنامج أول مرة**
   - يظهر معرّف الجهاز (HWID)
   - مثال: `A1B2C3D4E5F6G7H8`

2. **العميل يرسل لك الـ HWID**
   - عبر واتساب أو إيميل

3. **أنت تولّد مفتاح التفعيل**
   ```bash
   python license_system.py generate A1B2C3D4E5F6G7H8 "محل الظافرية"
   ```
   - يظهر مفتاح مثل: `A1B2-C3D4-E5F6-G7H8`

4. **تعطي المفتاح للعميل**
   - العميل يدخله في البرنامج
   - يتم التفعيل ✅

5. **البرنامج يعمل على هذا الجهاز فقط**
   - لو حاول ينقله لجهاز تاني: يرفض يشتغل ⛔

### 👉 خطوة بخطوة:

   - يشغّل `Zafrya-Store.exe`
   - يظهر له HWID

2. **العميل يرسل لك الـ HWID**
   - مثل: `A1B2C3D4E5F6G7H8`

3. **تولّد مفتاح وترسله**
   ```bash
   python license_system.py generate A1B2C3D4E5F6G7H8 "اسم العميل"
   ```

4. **العميل يدخل المفتاح**
   - يتم التفعيل ✅

## ⚠️ ماذا يحدث لو...

### 🚫 العميل حاول ينقل البرنامج لجهاز تاني؟
- يظهر له: **"هذا البرنامج مرخّص لجهاز آخر"**
- لازم يطلب مفتاح جديد منك
- ويدفع مرة ثانية 💰

### 🚫 العميل حاول يشارك البرنامج مع أصدقاءه؟
- هما يقدروا ينسخوا الملفات
- **لكن** لما يشغّلوا على جهاز ثاني:
  - يرفض يشتغل ⛔
  - لازم مفتاح جديد = دفع جديد 💵

## 🔒 الأمان

### الحماية من:
- ✅ النسخ غير المشروع
- ✅ الاستخدام على أجهزة متعددة
- ✅ التلاعب بملف الترخيص
- ✅ مشاركة البرنامج مع الآخرين

### تقنية الحماية:
- **Hardware ID (HWID)**: معرّف فريد لكل جهاز
- **MAC Address**: عنوان كرت الشبكة
- **CPU Serial**: رقم المعالج
- **SHA-256 Encryption**: تشفير قوي

## 💰 نموذج الربح

### طريقة بيع مقترحة:

1. **النسخة التجريبية**: مجانية 7 أيام
   - للتجربة فقط
   - لو عجبه يدفع

2. **ترخيص جهاز واحد**: مثلاً 1000 جنيه
   - يعمل على جهاز واحد فقط
   - لو عايز جهاز تاني: يدفع مرة ثانية

3. **الدعم الفني**:
   - مجاني لمدة شهر
   - بعدها: 100 جنيه/شهر (اختياري)

4. **التحديثات**:
   - مجانية لسنة
   - بعدها: 200 جنيه/سنة
